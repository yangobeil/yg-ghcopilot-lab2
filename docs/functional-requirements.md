# Functional Requirements

## TODO App Features

### 1. Group Todos by Topic
**Description:** Users should be able to organize todos into groups based on topics, with each group displayed under its own subtitle.

**Requirements:**
- Users can create custom topic groups/categories
- Todos can be assigned to a specific topic group
- Topics are displayed as subtitles or section headers
- Todos are visually grouped under their respective topic sections

### 2. Move and Delete Todos
**Description:** Users should be able to manage the position and existence of their todos.

**Requirements:**
- Users can move todos between different topic groups
- Users can reorder todos within a topic group
- Users can delete individual todos
- Deletion should be intuitive (confirm action or undo capability)

### 3. Add Due Dates to Todos
**Description:** Users should be able to assign and manage due dates for their todos.

**Requirements:**
- Users can set a due date when creating or editing a todo
- Users can modify or clear an existing due date
- Due dates are visually displayed with each todo
- Todos can be filtered or sorted by due date
- The system should highlight or notify users of upcoming or overdue todos
